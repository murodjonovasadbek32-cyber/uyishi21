# Alivio — React + Vite

Reference images asosida tayyorlangan responsive React sahifa.

## Ishga tushirish

```bash
npm install
npm run dev
```

## Tekshirish va build

```bash
npm run lint
npm run build
npm run preview
```

Vercel: Framework Vite, Build Command `npm run build`, Output Directory `dist`.

Asosiy kod: `src/App.jsx`. Dizayn: `src/App.css`. Rasmlar: `public/images`.

Start Trial / Find Your Way tugmalari brauzerda saqlanadigan demo kundalikni ochadi.
Sign in va Pricing demo oynalar: server, to‘lov va akkaunt tizimi ulanmagan.
Video berilmaganligi sabab play tugmasi rasmli preview oynasini ochadi.

Rasmlar manbasi: https://github.com/niiknikk/Alivio-Landing-Page/tree/main/img
